## How to set it up localy

1. clone the repo
```powershell
git clone https://github.com/MohammedAref11/TODO-App.git
```

2. move to main file
```powershell
cd "TODO-App"
```

3. install required dependencies
```powershell
npm install
```

4. To run the website localy run 
```powershell
npm run dev
```
